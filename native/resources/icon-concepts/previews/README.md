# Generated icon previews

Run `python3 tools/render-icon-concepts.py` from `native/` to regenerate.

The 24 numbered PNGs are 1024 × 1024 exports of the sibling SVG sources.
`contact-sheet-1.png` shows concepts 1–12; `contact-sheet-2.png` shows 13–24.
`small-sizes.png` compares each mark at 64, 32, and 16 pixels.
`report.json` records validation results and output hashes.

These previews do not replace `resources/icon.png` or `resources/Hexes.icns`.
